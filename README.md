# nyonic-sites

The hand-managed static sites under nyonic.com, one directory each. Until
22 Sep 2026 these lived loose on one drive with no version control.

| Site | Kind |
|---|---|
| `appliancecalls` `autocalls` `electriccalls` `garagecalls` `hvaccalls` `lawncalls` `lockcalls` `plumbcalls` `restorecalls` `roofcalls` `septiccalls` `towcalls` | **Generated** by `deckhouse/calldeck/scripts/brands.mjs`. Edit the brand spec there, not the HTML; regenerating overwrites `index.html`, the marks and the deploy config. |
| `pizzacalls` `pestcalls` `treecalls` `snowcalls` | **Hand-written.** The original four; the generator was modelled on them. `index.html` is the source. |
| `rivalstd-landing` | Rivals Tournament Director. Brought in with its own history via `git subtree`; its old repo is `dietwedge/rivalstd-landing`. |

`terms.html` and `privacy.html` on all sixteen calls sites are generated by
`deckhouse/calldeck/scripts/legal.mjs`, and `deckhouse/calldeck/test/legal.test.js`
asserts the privacy policy still matches what the pages actually do.

## Deploying

    HOST=51.81.33.29 bash vps/sync-static.sh <dir> <dir>.nyonic.com

from the `ai-business` working tree. `sync-static.sh` resolves the directory
under `nyonic-sites/` on its own. It excludes what is never web content —
`README.md`, `build.py`, anything underscore-prefixed, `brand/`, `source/` —
because all of those were found being served with a 200 before the excludes
existed.

## What these pages promise

No cookies, no analytics, no storage, no forms, nothing loaded from anybody
else's server, and no personal email address anywhere. The privacy policy says
so, and the test suite fails if it stops being true.
